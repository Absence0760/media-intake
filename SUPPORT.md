# Support

- Usage: read `README.md` and `docs/`, then search the issues.
- Bugs: open an issue with what you expected, what happened, the steps, your
  OS and the commit SHA. Never attach real photos or unredacted paths;
  reproduce with synthetic files.
- Security problems: see `SECURITY.md`, never a public issue.
- Contributing: `CONTRIBUTING.md`.

This project is maintained on a best-effort basis; there is no paid support.
